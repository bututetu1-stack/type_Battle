## 3. 次にやること（利用者の最新の依頼）

利用者の言葉（原文）:

> 設定画面の上にバトル画面の上部が映っているのがすごく気になる。
> 設定画面の文字が小さく見づらいのでフォントサイズをもう少し大きく。

> 次はデザインの改善を主に進めて下さい。

### 3-1. 設定画面の上にバトル画面がはみ出す【原因特定済み】

- 症状: ソロの開始画面（設定オーバーレイ）の上、ヘッダーとの間の帯（約64px）に、
  後ろのバトル画面（敵のミニ盤面の上端）が見えている。
- 原因（ブラウザで実測して確認済み）: 設定オーバーレイは `fixed top-16`（`SoloGame.tsx` の
  `{(gameState === 'start' || settingsOpen) && (` の直後）だが、親の `<main>` に常に
  `style={{ transform: hitStop && keyCfg.screenShake ? 'scale(1.015)' : 'scale(1)' }}` が付いている。
  `transform` が `none` 以外だと、`fixed` の基準が画面ではなく `<main>` になるため、
  `<main>` の上端（64px）＋ `top-16`（64px）＝ 128px の位置に出てしまう。
  `transform` を外すと 64px（ヘッダー直下）に来ることを確認済み。
- 直し方の候補: オーバーレイを `createPortal(…, document.body)` で `<main>` の外に出す（推奨。
  ヒットストップ演出の有無に関係なく確実）。または `transform` を演出中以外は `none` にする
  （ただし `transition: transform` 中も基準が変わる点に注意）。
- 結果画面（TOP OUT / YOU WIN / TIME UP）は `absolute inset-0` なので影響なし。

### 3-2. 設定画面の文字を大きく

- 設定オーバーレイ内は `text-[10px]` `text-[11px]` `text-xs` が多い。全体で 9〜11px 指定が 156 箇所、
  `text-xs` が 59 箇所ある。本文は最低 13〜14px、補足でも 12px 程度を目安に。
- 設定項目が多く縦に長いので、大きくするなら横に並べる・折りたたむ工夫が要る。

### 3-3. Tab で即リスタート ＋ 開始前カウントダウン（他サイトの定番）

- Tab: Monkeytype 風。プレイ中・結果画面のどこでも Tab で即やり直し。ブラウザのフォーカス移動を
  止めるため `preventDefault()` が必要。現在のキー処理は `SoloGame.tsx` の `handleKeyDown`
  （開始・リトライは Space で `startGame()`）。キー設定（`lib/keyconfig.ts`）の割り当てと衝突しないか確認。
- カウントダウン: 開始時に「3・2・1・GO」。表示中は打鍵を受け付けない。タイムアタックの残り時間・
  `startTime`（KPS や速度推移グラフの基準）は GO の時点から数え始めること。
  オンラインには同期開始用のカウントダウン（`room.ts` の `COUNTDOWN_MS`）が既にある。今回はソロが対象。

### 3-4. デザインの大幅改善（今回の主題）

前セッションで測った「安っぽく見える原因」:

- 文字が小さすぎる: 9〜11px 指定 156 箇所。
- 色がトークン外: `bg-neutral-800` `text-gray-400` `border-white/10` などの直書きが 204 箇所
  （トークン使用は 337 箇所）。テーマと馴染まず、画面ごとに質感がバラつく。
- 見出しやボタンに絵文字: 28 箇所（⚔ 🏆 🏅 🌐 🟨 👑 など）。安っぽさの大きな原因。線画アイコン
  （lucide-react、既に導入済み）に揃えたい。
- 角丸が 7 種類混在（`rounded` 〜 `rounded-2xl`）。
- 結果画面が状態ごとの濃い単色（`bg-red-950/90` `bg-emerald-950/90` `bg-indigo-950/90`）で面全体を塗っている。
- 発光・影の直書きが 25 箇所。グローを多用していて、どこが大事か分からない。
- 開始画面: 巨大な剣アイコン＋「Press [SPACE] to Start」（灰色の等幅）で弱い。設定はスライダーが縦に長く並ぶ。

方向性の案（利用者とはまだ合意していない。着手前にスクリーンショット付きで確認を取るとよい）:

- 今の「計器HUD」の世界観は活かし、**抑制して質を上げる**方向。
- 文字の段階を決めて守る（例: 12 / 14 / 16 / 20 / 28 / 40px）。余白も段階を決める。
- 角丸は 2 種類程度に（例: 小 8px / カード 14px）。
- 色はトークンだけを使う。直書きのグレーをトークンへ置き換える。
- アイコンは lucide に統一し、絵文字はアイテム表示など意味のある所だけに残す。
- 発光は「いま打っているお題」と「主要ボタン」だけに絞る。
- 結果画面は、中立の暗幕の上にカードを置き、状態の色は細い帯や見出しだけに使う。
- 開始画面は、大きな「スタート」ボタン＋キー表示（`Space`）にし、モード選択を主役に、詳細設定は折りたたむ。
- 変更のたびに、1920×1080 と 1366×768 でスクリーンショットを撮って確認する。
